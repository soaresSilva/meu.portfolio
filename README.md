# Portfólio de Alisson Silva

Portfólio pessoal desenvolvido para apresentar meus projetos, estudos e evolução como desenvolvedor de software.

> Projeto em desenvolvimento. A estrutura atual utiliza Next.js, React e Tailwind CSS; novas seções e projetos serão adicionados progressivamente.

## Objetivos

- Apresentar projetos funcionais e estudos de caso.
- Registrar as tecnologias utilizadas e as decisões de implementação.
- Disponibilizar links para demonstrações, código-fonte e contato.
- Praticar componentização, navegação, acessibilidade e publicação de aplicações web.

## Tecnologias

- **Next.js** e **React** para a aplicação web.
- **JavaScript** para a lógica da interface.
- **Tailwind CSS** para estilização.
- **Vercel** como plataforma planejada de publicação.

## Executar localmente

### Pré-requisitos

- Node.js instalado.
- npm, pnpm, yarn ou bun.

### Instalação

```bash
git clone https://github.com/soaresSilva/meu.portfolio.git
cd meu.portfolio
npm install
npm run dev
```

Depois, acesse [http://localhost:3000](http://localhost:3000).

### Outros comandos

```bash
npm run build
npm run start
```

## Estrutura inicial
